Scope & privacy notes
Pre-release NU7 V6 Ironwood-only PCZTs, 1–8 actions. Other pools and Unified Addresses are not supported.
PCZTs can contain private viewing data. Trust in the delivered page, WASM and browser is required. Clear removes app data, not a guarantee of memory erasure.

            

            
A matching comparison is not evidence that a payment happened, or that a transaction can be accepted by a network.
